# SmartOnboard UI/UX Brief

## Design Goal

Create a premium hiring ecosystem experience.

The platform should feel:

* Trustworthy
* Professional
* Modern
* AI Assisted
* Enterprise Ready

---

# Candidate Experience

Focus:

Clarity and confidence.

Candidates should immediately understand:

* Which jobs fit them
* Why they fit
* What action to take

---

# Job Cards

Each card should show:

* Position
* Company
* Location
* Applicability Percentage
* Best Matching Resume

Applicability should be visually prominent.

---

# Candidate Dashboard

Sections:

* Recommended Jobs
* Applications
* Interviews
* Resume Library

Most important information appears first.

---

# Resume Library

Display:

Resume Name

Resume Type

Last Updated

Primary Skills

Allow:

* Upload
* Replace
* Delete

Maximum:

3 resumes

---

# Recruiter Experience

Focus:

Decision making.

Recruiters should spend minimal time searching for qualified candidates.

---

# Applicant Cards

Display:

* Name
* Match Score
* Risk Score
* Authenticity Score
* Evidence Score

Visual indicators should highlight concerns.

---

# AI Hiring Brief

Top dashboard widget.

Displays:

* Total Applicants
* Strong Matches
* Tailored Resumes
* High Risk Candidates
* Interview Recommendations

---

# Navigation

Primary Navigation:

Candidate:

* Job Feed
* Applications
* Interviews
* Resume Library
* Profile

Recruiter:

* Jobs
* Applicants
* Interviews
* Billing
* Settings

Legacy modules should not appear in primary navigation.

---

# Accessibility

Support:

* Keyboard Navigation
* Responsive Layouts
* High Contrast Text
* Mobile Friendly Interfaces
