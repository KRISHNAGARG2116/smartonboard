# SmartOnboard Product Requirements Document

## Candidate Features

### Candidate Registration

Requirements:

* Email OTP Verification
* SMS OTP Verification
* Candidate Profile Creation

---

### Resume Library

Requirements:

* Up to 3 resumes
* Resume Parsing
* Skill Extraction
* Unified Skill Graph

---

### Job Feed

Requirements:

* Personalized Recommendations
* Applicability Percentage
* Best Matching Resume
* Matching Skills
* Missing Skills

---

### Applications

Requirements:

* Application Tracking
* Immutable Application Snapshots

Statuses:

* Applied
* Interview Scheduled
* Offer Received
* Closed

---

### Interviews

Requirements:

* Recruiter-defined slots
* Candidate slot selection
* Calendar integration
