# SmartOnboard Application Flow

## Landing Page

Users enter SmartOnboard and choose one of two paths:

[ Looking For A Job ]

or

[ Hiring Talent ]

---

# Candidate Flow

Landing Page

↓

Candidate Registration

↓

Email OTP Verification

↓

SMS OTP Verification

↓

Create Candidate Profile

↓

Upload Initial Resume

↓

Enter Candidate Dashboard

---

# Candidate Dashboard

Sections:

* Job Feed
* Resume Library
* Applications
* Interviews
* Profile

---

# Resume Library

Candidate may upload up to 3 resumes.

Examples:

* AI Engineer Resume
* Product Manager Resume
* Founder Resume

System extracts:

* Skills
* Experience
* Education
* Certifications
* Projects

All resumes contribute to a unified skill graph.

---

# Job Feed

Each job card displays:

* Company
* Position
* Location
* Applicability Percentage
* Best Matching Resume

Example:

91% Match
Using AI Resume

76% Match
Using Product Manager Resume

---

# Job Details

Candidate can view:

* Job Description
* Requirements
* Matching Skills
* Missing Skills
* Why Recommended

Candidate cannot view:

* Risk Scores
* Authenticity Scores
* Internal Rankings

---

# Job Application

Candidate clicks Apply.

System displays available resumes.

Candidate selects one resume.

Selected resume becomes immutable application snapshot.

Future edits do not affect submitted applications.

---

# Applications Page

Statuses:

* Applied
* Interview Scheduled
* Offer Received
* Closed

No internal recruiter stages are exposed.

---

# Interviews Page

Displays:

* Interview Date
* Interview Time
* Recruiter Information
* Meeting Link

If no interviews exist:

"No interviews scheduled."

---

# Recruiter Dashboard

Sections:

* Jobs
* Applicants
* Interviews
* Company Settings
* Billing

Legacy onboarding systems remain hidden.

---

# Job Creation

Recruiter creates:

* Title
* Description
* Requirements
* Skills
* Closing Date (Optional)

Default:

Job remains open indefinitely.

---
